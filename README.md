# BSV-Dynamic-NPC-Cleaner-Poly-QBOX-QBX-Sistema-profissional.
BSV Dynamic NPC Cleaner Poly — QBOX/QBX  Sistema profissional de controle de NPCs para servidores FiveM QBOX/QBX.
Crie zonas dinâmicas no mapa para remover:

✔ NPCs pedestres
✔ trânsito NPC
✔ veículos de ambientação
✔ spawn automático de NPCs

Tudo isso SEM afetar o restante da cidade.

🔥 Diferenciais
✔ Sistema totalmente independente
✔ Compatível com QBOX/QBX
✔ Zonas circulares
✔ Zonas desenhadas manualmente (PolyZone)
✔ Salvamento automático
✔ Sincronização em tempo real
✔ Não remove players
✔ Não afeta veículos de players
✔ Não quebra a densidade global da cidade
✔ Ideal para eventos, arenas, facções, ilhas e Battle Royale
🧠 Como funciona

O admin pode criar áreas anti-NPC diretamente no mapa.

Zona Circular
/npczone 300

Cria uma área circular de 300 metros no local atual.

Zona Desenhada (Poly)
/npczonepoly

Modo profissional de desenho de área.

Controles:
E = marcar ponto
ENTER = salvar área
BACKSPACE = cancelar

Desenhe:

✔ favelas
✔ arenas
✔ ilhas
✔ condomínios

✔ MLOs
